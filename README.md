# **Проект интернет-магазина**
## Описание 
- Реализация ядра для интернет-магазина. 
## Структура проекта
- manager.py - управляющий файл проекта
- catalog - директория приложения catalog
- catalog/templates - директория с шаблонами html-страниц

- blog - директория приложения Blog
- blog/templates - директория с шаблонами html-страниц
- 
- static/css - директория со стилями html
- static/js - директория со скриптами

## Установка
- Клонируйте репозиторий:
```git clone git@github.com:VolkovaSSS/pythonProject1.git```
- Установите зависимости
- создайте файл .env по шаблону .env.sample
## Использование
Для использования нужно запустить файл main.py
например: python main.py
### Зависимости
- Python 3.x
- requests = ">=2.25.1"
- flask = ">=2.0.1"
